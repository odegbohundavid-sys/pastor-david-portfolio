# Pastor David Odegbohun portfolio

A static personal ministry website ready for free deployment on Vercel or Netlify.

## Publish on Vercel

1. Create a GitHub repository and upload these files.
2. In Vercel, select **Add New → Project**, then import the repository.
3. Leave the framework preset as **Other** and click **Deploy**.
4. In the Vercel project settings, add your custom domain when you are ready.

## Before publishing

- The Contact section is linked to `odegbohundavid@gmail.com`. Add a form service later if you want messages to be sent from a website form.
- Replace the “coming soon” teaching links with YouTube/video and MP3/audio links.
- Add the remaining book files and cards to the Free books section.

The supplied Google Drive file is linked as an audio teaching. The supplied Facebook page is linked from the Contact section.
